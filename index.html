VLA / Unified JSON ↔ CSV converter

Converts either a Label Studio VLA export or a unified schema JSON (tier1/tier2/tier3) to the master / unique spreadsheet, and back — the source format is auto-detected. All processing is local — nothing is uploaded.

JSON → CSV / Excel

Upload one .json — either a unified schema (tier2/tier3) or a Label Studio VLA export; detected automatically. Unified adds a body part column (available directly, no guessing). Excel output = one file with a master tab and a unique tab; master's t2/t3 cells are live formulas into unique (edit a description on the unique tab → every matching master row updates). CSV output = two plain files, no linking (CSV can't hold tabs or formulas).

CSV / Excel → JSON

Upload the .xlsx (both tabs) or a single master .csv. A cell you typed over directly always wins; an untouched cell still follows its linked unique-tab text. Output schema is auto-detected from the sheet: has a body part column → rebuilds the unified schema; otherwise rebuilds a Label Studio VLA export. Fields not carried by the sheet (objects, relations, keypoints, QC, tier1 caption) are emitted empty.

master columns: t3 start · t3 end (child segment frames) · t2 start · t2 end (parent action frames) · t2 id · t2 · t3 id · t3 · body part (unified schema only). Frames are plain integers so spreadsheets won't turn them into dates. In the .xlsx, t2/t3 are VLOOKUP formulas resolving the ids against the unique tab.
unique columns: t2 id · Unique t2 · t2 occurrences · t3 id · Unique t3 · t3 occurrences (two independent lists, side by side). Edit text in the Unique t2 / Unique t3 columns; do not change the id columns.
Editing rule: retyping a master t2/t3 cell directly always sticks, even if the unique tab still has the old text for that id. Leave a master cell alone and it keeps following unique — so editing unique is how one change updates every row that shares it.
Round-trip: every T2 frame range is preserved exactly. From the unified schema, body part round-trips exactly too (it's a real column, not guessed). From a legacy VLA export the per-T3 body-part label isn't carried in master at all, so it's rebuilt as a placeholder ("segment").
