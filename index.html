VLA JSON ↔ CSV converter

Converts a Label Studio VLA video export to the master / unique spreadsheet, and back. All processing is local — nothing is uploaded.

JSON → CSV / Excel

Upload one VLA .json. Excel output = one file with a master tab and a unique tab; master's t2/t3 cells are live formulas into unique (edit a description on the unique tab → every matching master row updates). CSV output = two plain files, no linking (CSV can't hold tabs or formulas).

CSV / Excel → JSON

Upload the .xlsx (both tabs; text is taken from the unique tab so your edits there are applied) or a single master .csv. Rebuilds a partial JSON in the same template. Fields not in the sheet (object labels, relations, boxes, body-part labels, QC) are emitted empty.

master columns: t3 start · t3 end (child segment frames) · t2 start · t2 end (parent action frames) · t2 id · t2 · t3 id · t3. Frames are plain integers so spreadsheets won't turn them into dates. In the .xlsx, t2/t3 are VLOOKUP formulas resolving the ids against the unique tab.
unique columns: t2 id · Unique t2 · t2 occurrences · t3 id · Unique t3 · t3 occurrences (two independent lists, side by side). Edit text in the Unique t2 / Unique t3 columns; do not change the id columns.
Round-trip: every T2 frame range is preserved exactly. Only the body-part label on each T3 segment is lost (rebuilt as "segment").
